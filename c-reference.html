C

Compile & run

C is translated to machine code before it runs. That extra step is where most beginners get stuck.
01

The compilergcc / clang

gcc --version      # linux, mingw on windows
clang --version    # mac (xcode-select --install)

Windows: install MinGW-w64, or use WSL. Mac: Xcode command line tools. Linux: apt install build-essential.

Build and runtwo steps

gcc hello.c -o hello     # compile -> a program
./hello                  # run it (mac/linux)
hello.exe                # run it (windows)

Without -o the output is called a.out. The .c file is source; the output is a standalone executable that no longer needs the compiler.

Flags worth usingalways

gcc -Wall -Wextra -g -std=c17 prog.c -o prog
-Wall -Wextraturn on warnings — they are real bugs
-gkeep debug info so gdb can help
-O2optimise for release builds
-std=c17pin the language version
-o namename the output
-lmlink the maths library (needed for math.h)
-fsanitize=addresscatch bad memory at runtime

Treat every warning as an error. C will happily compile code that crashes.

Hello, worldhello.c

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
#includepaste in another file's declarations before compiling
<stdio.h>standard input/output — where printf is declared
int main(void)where execution starts; returns an int to the OS
{ }a block; C ignores your indentation entirely
;ends every statement — not optional
\nnewline; printf does not add one
return 00 means success, anything else means failure

Commentsignored text

// to the end of the line
/* several
   lines */

What actually happensfour stages

1 Preprocess#include and #define are expanded, comments stripped
2 CompileC → assembly → object file .o
3 Assembleobject code, one per source file
4 Linkobject files + libraries → one executable
gcc -E f.c    # stop after preprocessing
gcc -S f.c    # stop at assembly
gcc -c f.c    # stop at f.o
gcc a.o b.o -o prog    # link them

The two error familiesread the stage

hello.c:4:5: error: expected ';' before '}'
   -> compiler error: a syntax problem

undefined reference to `sqrt'
   -> linker error: add -lm

A compiler error names a file and line. A linker error names a missing function — you declared it but never supplied the code or the library.

Arguments from the shellargc / argv

int main(int argc, char *argv[]) {
    // argv[0] is the program name
    for (int i = 1; i < argc; i++)
        printf("%s\n", argv[i]);
    return 0;
}

Anatomy & types

Every variable is declared with a type before use, and that type is fixed forever.
02

Declaring variablestype name = value;

int count = 0;
double price = 9.99;
char grade = 'A';       // single quotes = one char
int a, b, c;            // several at once
int x;                  // UNINITIALISED = garbage
const int MAX = 100;    // cannot be reassigned

An uninitialised local variable holds whatever was in that memory. Always give a starting value.

Castingforcing a type

Integer / integer is integer division, even when assigned to a double. Cast one side first.

printf & scanf

Text in, text out. The format string is a tiny language of its own.
03

printfoutput

printf("plain text\n");
printf("%d items\n", count);
printf("%s is %d\n", name, age);
printf("%.2f\n", 3.14159);    // 3.14
printf("%5d|\n", 42);         //    42|
printf("%-5d|\n", 42);        // 42   |

printf("%+d\n", 42);          // +42

Each % code is filled from the arguments, left to right. The count and the types must match exactly — nothing checks this at runtime.

scanfinput, carefully

int age;
scanf("%d", &age);        // & = address of age

char name[50];
scanf("%49s", name);      // stops at whitespace
                          // 49 protects the buffer

if (scanf("%d", &n) != 1) {
    // ALWAYS check the return: it counts
    // the items successfully read
}

Forgetting & on a scanf argument corrupts memory instead of failing. Arrays are the exception — they are already addresses.

Why scanf hurtsthe leftover newline

scanf("%d", &n);      // leaves the \n in the buffer
fgets(line, n, stdin);     // instantly reads that \n

// fix: consume the rest of the line
int c; while ((c = getchar()) != '\n' && c != EOF);

Read lines properlyfgets

char line[256];
if (fgets(line, sizeof line, stdin)) {
    line[strcspn(line, "\n")] = '\0';   // trim newline
    printf("you said: %s\n", line);
}

int n = atoi(line);              // text -> int
long v = strtol(line, NULL, 10); // better: detects errors

fgets + strtol is the safe pattern for reading numbers from a person. gets() was removed from the language for being impossible to use safely.

Operators

Arithmetic, comparison, logic, bits, and the precedence table you will keep coming back to.
04

Arithmeticmaths

+ - * /int / int truncates: 7/2 == 3
%remainder, integers only: 7%2 == 1
++x --xchange, then use the new value
x++ x--use the old value, then change
+= -= *= /= %=compound assignment
int i = 5;
int a = i++;   // a=5, i=6
int b = ++i;   // b=7, i=7

// C has no ** operator:
#include <math.h>
pow(2, 10);    // 1024.0  (and link with -lm)

Comparison & logicresult is 0 or 1

== !=equal / not equal
< <= > >=ordering
&&AND, short-circuits
||OR, short-circuits
!NOT
if (p != NULL && p->ready)   // safe: && stops early
if (x = 5)     // assigns! compiles! always true!
if (x == 5)    // what you meant

There is no bool check: if (x) means x != 0. Any non-zero value is true.

Bitwiseraw bits

&AND — mask bits off
|OR — turn bits on
^XOR — flip where different
~NOT — flip every bit

&= |= ^= <<= >>=compound forms

flags &= ~MASK;    // clear
flags ^=  MASK;    // toggle

&& is logic, & is bits. Swapping them compiles silently and gives wrong answers.

Ternary?:

*p++ means *(p++). a & 1 == 0 means a & (1 == 0). Bracket anything involving bit operators.

Integer promotionthe invisible rule

char a = 100, b = 100;
int  c = a + b;      // 200: both promoted to int first

unsigned char x = 250;
if (x + 10 > 255)    // TRUE: the sum is an int, not a char

unsigned u = 1; int s = -1;
if (s < u)           // FALSE: s converts to a huge unsigned

Anything smaller than int is promoted to int before arithmetic. When the two sides differ after that, the smaller rank converts to the larger, and signed converts to unsigned at equal rank. That last step is the one that bites.

Evaluation orderundefined

i = i++ + 1;          // undefined behaviour
f(i++, i);            // argument order unspecified
arr[i] = i++;         // undefined

Modifying the same variable twice in one statement has no defined meaning. The compiler may do anything at all. Split it into two statements.

Control flow

Branching and looping. Braces group statements; indentation means nothing to the compiler.
05

if / elsebranching

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'F';
}

if (x > 0)
    printf("positive\n");   // braces optional for ONE
                            // statement -- add them anyway

if (x) do_a(); do_b(); — do_b() always runs. Missing braces cause real outages.

switchjump on a value

switch (ch) {
    case 'a':
    case 'A':
        handle_a();
        break;          // without it, execution
    case 'b':           // FALLS THROUGH to the next case
        handle_b();
        break;
    default:
        unknown();
        break;
}

Only works on integer-like values (int, char, enum) — not strings, not floats, not ranges.

forthe workhorse

for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}
//    setup    test       step

for (int i = 10; i > 0; i--)         // count down
for (int i = 0; i < n; i += 2)       // step by 2
for (int i = 0, j = n-1; i < j; i++, j--)
for (;;) { /* ... */ }                     // forever

The test runs before every pass, including the first. Declaring i inside keeps it local to the loop (C99 and later).

while / do-whiletwo shapes

while (count > 0) {       // test FIRST
    count--;              // may run zero times
}

do {
    ch = getchar();       // body runs at least ONCE,
} while (ch != '\n');     // then tests
// note the semicolon after while

break / continueinside loops

for (int i = 0; i < n; i++) {
    if (skip[i]) continue;   // next iteration
    if (found)     break;    // leave the loop
}

break leaves one loop or one switch, never two. For nested loops, use a flag or goto.

gotoone honest use

int load(void) {
    FILE *f = fopen("a", "r");
    char *buf = malloc(100);
    if (!buf)  goto fail_buf;
    if (!read(f, buf)) goto fail_read;
    /* ... */
    return 0;

fail_read:
    free(buf);
fail_buf:
    if (f) fclose(f);
    return -1;
}

Jumping backwards or into a block is chaos. Jumping forward to a single cleanup label is the standard C idiom for releasing resources on error, used throughout the Linux kernel.

Common loop shapespatterns

// every element
for (int i = 0; i < n; i++) sum += a[i];

// every character of a string
for (int i = 0; s[i] != '\0'; i++)

// walk with a pointer
for (char *p = s; *p; p++)

// read until end of input
int c;
while ((c = getchar()) != EOF) putchar(c);

// read lines
char line[256];
while (fgets(line, sizeof line, stdin)) { /* ... */ }

Functions

Declare it, define it, call it. Arguments are always copied.
06

Anatomydefinition

int add(int a, int b) {     // return type, name, params
    return a + b;
}

void greet(const char *name) {   // void = returns nothing
    printf("hi %s\n", name);
}

int roll(void) {           // (void) = takes nothing
    return rand() % 6 + 1;  // () means "unspecified" - avoid
}

Prototypesdeclare before use

int add(int, int);      // prototype: no body

int main(void) {
    printf("%d", add(2, 3));   // now legal
}

int add(int a, int b) { return a + b; }

C reads your file top to bottom and must know a function's shape before the first call. Either define it above, or write a prototype at the top — which is what header files are for.

Pass by valueeverything is copied

void broken(int x) { x = 99; }     // changes a copy
void works(int *x) { *x = 99; }    // changes the original

int n = 1;
broken(n);   // n is still 1
works(&n);   // n is now 99

To let a function modify your variable, pass its address. This is why scanf needs &.

Returningone value only

return;             // from a void function
return value;       // ends the function immediately

// need several results? use out-parameters:
void divide(int a, int b, int *q, int *r) {
    *q = a / b;
    *r = a % b;
}
int q, r;
divide(7, 2, &q, &r);

// or return a struct
Point make(int x, int y) {
    Point p = {x, y};
    return p;      // the struct is copied out: safe
}

Never return a pointer to a local variable — that memory is gone the moment the function returns.

Arrays as argumentsthey decay

void f(int arr[], int n);   // identical to:
void f(int *arr, int n);

// sizeof(arr) inside f gives the POINTER size,
// not the array size. Always pass the length.

Storage classeslifetime & visibility

static int counter = 0;    // at file scope:
                           // private to this file

void tick(void) {
    static int calls = 0;  // inside a function:
    calls++;               // survives between calls,
}                          // initialised once

extern int shared;         // defined in another file

inline int sq(int x) { return x*x; }   // hint to inline
static globalinvisible to other files — the C way to say private
static localone copy, keeps its value, zero-initialised
externthe definition lives elsewhere; goes in headers
constread-only after initialisation

Recursioncalling itself

long fact(int n) {
    if (n <= 1) return 1;    // base case FIRST
    return n * fact(n - 1);
}

No base case, or one you never reach, means stack overflow — a crash, not an exception.

main's return valueexit status

return 0;          // success
return 1;          // failure
exit(EXIT_FAILURE) // from anywhere, stdlib.h

Arrays

A fixed block of identical items, back to back in memory.
07

Declaringtype name[size];

int nums[5];                    // 5 ints, uninitialised
int nums[5] = {1, 2, 3, 4, 5};
int nums[5] = {1, 2};           // rest are 0
int nums[]  = {1, 2, 3};        // size inferred: 3
int zeros[100] = {0};           // all zero
char name[20] = "Ada";          // 3 chars + NUL

nums[0]        // first
nums[4]        // last of 5
nums[5]        // OUT OF BOUNDS -- no error, just wrong

C never checks array bounds. Reading or writing past the end silently corrupts other data or crashes later, far from the real bug.

Sizecounting elements

int n = sizeof(nums) / sizeof(nums[0]);

// works ONLY where the array was declared.
// Once passed to a function it is a pointer,
// so pass the length alongside it:
void print(int *a, size_t n);

Loopingthe standard shape

for (size_t i = 0; i < n; i++) {
    printf("%d ", nums[i]);
}

int sum = 0;
for (size_t i = 0; i < n; i++) sum += nums[i];

// find
int idx = -1;
for (size_t i = 0; i < n; i++)
    if (nums[i] == target) { idx = i; break; }

2D arraysrows and columns

int grid[3][4];                   // 3 rows, 4 columns
int grid[2][3] = {{1,2,3},{4,5,6}};
grid[1][2] = 9;

for (int r = 0; r < 3; r++)
    for (int c = 0; c < 4; c++)
        printf("%d ", grid[r][c]);

void f(int g[][4], int rows);   // all but the first
                                // dimension required

Stored row by row in one flat block. grid[1][2] is really *(base + 1*4 + 2).

Variable length arraysC99, use with care

void f(int n) {
    int tmp[n];     // size decided at runtime
}

Lives on the stack, so a large n overflows it. Optional since C11 — prefer malloc.

Arrays are not pointersbut they act like it

int a[5];
a        // decays to &a[0] in almost every context
*a       // a[0]
a + 1    // &a[1]  -- pointer maths counts ELEMENTS
*(a+2)   // a[2]   -- identical to a[2]

sizeof(a)   // 20: the whole array (where declared)
int *p = a;
sizeof(p)   // 8: just the pointer

An array name is not a variable holding an address — it is the block, and converts to a pointer to its first element on use. That one distinction explains most array confusion.

Copyingno assignment

int b[5] = a;     // illegal
b = a;            // illegal

memcpy(b, a, sizeof a);       // correct
for (int i=0;i<5;i++) b[i]=a[i];

Sorting and searchingstdlib

int cmp(const void *x, const void *y) {
    int a = *(const int *)x, b = *(const int *)y;
    return (a > b) - (a < b);
}
qsort(nums, n, sizeof nums[0], cmp);

int key = 7;
int *hit = bsearch(&key, nums, n,
                   sizeof nums[0], cmp);
C

Pointers

A variable holding an address. This is the whole language in one idea.
08

The two operators& and *

int x = 42;
int *p = &x;     // p holds the ADDRESS of x

&x               // "address of x"
*p               // "the value at p"  -> 42
*p = 99;         // writes THROUGH p: x is now 99
p                // the address itself, e.g. 0x7ffd...

printf("%p\n", (void *)p);
printf("%d\n", *p);

Read a declaration right to left: int *p is “p is a pointer to int”. The * in a declaration marks the type; the * in an expression fetches the value.

Why botherthree reasons

  • Let a function change your variable (scanf("%d", &n)).
  • Pass something big without copying it.
  • Build structures whose size is not known until the program runs — lists, trees, buffers.

NULLpoints at nothing

int *p = NULL;        // the only safe "empty" value
if (p != NULL) *p = 1;
if (p) *p = 1;        // same thing, idiomatic

int *q;               // uninitialised: holds garbage,
                      // NOT null. Always set it.

Dereferencing NULL is an instant crash (segmentation fault). Dereferencing garbage is worse: it may appear to work.

Pointer arithmeticcounts elements

int a[] = {10, 20, 30};
int *p = a;

*p        // 10
p++;      // advances by sizeof(int) = 4 bytes
*p        // 20
*(p + 1)  // 30
p[1]      // 30   -- identical to *(p+1)

int *end = a + 3;
for (int *q = a; q < end; q++) printf("%d", *q);

end - a   // 3: the distance in elements

Adding 1 to a pointer moves by the size of what it points at, not by one byte.

const and pointersread right to left

const int *ppointer to a constant int — cannot write *p
int * const pconstant pointer — cannot move p
const int * const pneither
void print(const char *s);   // promises not to
                             // modify the string

Pointer to pointer**

int x = 1;
int *p = &x;
int **pp = &p;
**pp        // 1

// used to let a function replace YOUR pointer:
void alloc(int **out) { *out = malloc(4); }
int *mine = NULL;
alloc(&mine);

void *a pointer to anything

void *raw = malloc(100);   // malloc returns void *
int *nums = raw;           // no cast needed in C

// cannot dereference a void * directly:
*raw;                      // error
*(int *)raw;               // cast first

// this is how qsort takes any type

The five ways pointers kill youlearn the names

Null dereferenceusing a pointer that is NULL
Dangling pointerusing memory after free, or a pointer to a dead local
Double freecalling free twice on the same block
Buffer overrunwriting past the end of an array
Memory leaklosing the last pointer to a block you allocated
free(p);
p = NULL;     // makes a later use fail loudly

Swap: the classicworked example

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int x = 1, y = 2;
swap(&x, &y);     // x=2, y=1
C

Strings

There is no string type. A string is a char array that ends in a zero byte.
09

What a string ischar + NUL

char s[] = "hi";     // actually {'h','i','\0'} -- 3 bytes
char *p = "hi";      // pointer to read-only memory

sizeof(s)    // 3  including the NUL
strlen(s)    // 2  up to, not including, the NUL

Every standard function finds the end by scanning for '\0'. Lose that byte and they run off into whatever follows.

char *p = "text" is a string literal: writing to p[0] is undefined and usually crashes. Use char s[] = "text" if you need to modify it.

Declaring and buildingbuffers

char buf[64];              // room for 63 chars + NUL
buf[0] = '\0';            // start empty

snprintf(buf, sizeof buf, "%s is %d", name, age);

char c = s[0];            // one character
s[0] = 'H';               // edit in place (arrays only)
for (int i = 0; s[i]; i++) putchar(s[i]);

if (n < 0 || (size_t)n >= sizeof dst)
    /* it was TRUNCATED: n is the length it WANTED */;

Stack vs heapthe model

StackLocals and parameters. Created on entry to a block, destroyed on exit. Fast, automatic, small (a few MB).
HeapEverything from malloc. Lives until you free it. Large, flexible, entirely your responsibility.
StaticGlobals and static locals. Exist for the whole program, zero-initialised.

    int a[100];               // stack: gone at return
    int *b = malloc(400);     // heap: yours until freed
    free(b);

Ownershipthe discipline C needs

  • Every malloc has exactly one matching free.
  • Write down, in a comment, who frees what.
  • Whoever allocates it usually frees it.
  • A function that returns heap memory must say so in its header comment.

Growable arrayworked example

typedef struct {
    int   *data;
    size_t len, cap;
} Vec;

int push(Vec *v, int x) {
    if (v->len == v->cap) {
        size_t cap = v->cap ? v->cap * 2 : 8;
        int *tmp = realloc(v->data, cap * sizeof *tmp);
        if (!tmp) return -1;
        v->data = tmp;
        v->cap  = cap;
    }
    v->data[v->len++] = x;
    return 0;
}

void vec_free(Vec *v) {
    free(v->data);
    v->data = NULL; v->len = v->cap = 0;
}

A 2-D array on the heaptwo ways

// 1. one flat block, index it yourself - preferred
int *g = malloc((size_t)rows * cols * sizeof *g);
g[r * cols + c] = 1;
free(g);

// 2. an array of row pointers
int **g = malloc(rows * sizeof *g);
for (int r = 0; r < rows; r++)
    g[r] = malloc(cols * sizeof *g[r]);
g[r][c] = 1;
for (int r = 0; r < rows; r++) free(g[r]);
free(g);

The flat block is one allocation, one free, and contiguous in cache. Use row pointers only when the rows differ in length.

Bit recipesthe five moves

x &= ~(1u << n)     // clear bit n

x &   (x - 1)       // clear the lowest set bit
x &   -x            // isolate the lowest set bit
#define SET(x,n)    ((x) |=  (1u << (n)))
#define CLR(x,n)    ((x) &= ~(1u << (n)))
#define GET(x,n)    (((x) >> (n)) & 1u)

If your program does any of these, the standard places no limit on what happens. The compiler may assume it never occurs and delete your checks. It is not “whatever the machine does”.

Integer trapssilent wrongness

unsigned u = 1;

                                      // unsigned is never < 0

Defend yourselfpractice

  • Compile with -Wall -Wextra -Wconversion.
  • Run tests under -fsanitize=address,undefined.
  • Use unsigned for bit work, signed for arithmetic.
  • Use size_t for sizes and indices.
  • Never rely on what your machine happens to do today.

The ruledeclare vs define

Header .hdeclarations, macros, typedefs, extern variables, static inline functions

staticmakes a function or global private to its .c file

A definition in a header that is included twice causes “multiple definition” at link time.

The traps, collectedlearn these once

Missing bracesonly the next statement belongs to the if

Style that prevents bugshabits

  • Always brace the body of if, for and while.
  • Initialise every variable where you declare it.
  • One job per function; keep them short enough to see whole.
  • const everything you do not intend to modify.
  • Check every return value: malloc, fopen, scanf, fread.
  • Free what you allocate, and set the pointer to NULL.
  • Compile with warnings on, and keep the output clean.
