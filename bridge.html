Memory and ownership

The section where two of the three columns are mostly a written reason why the question does not arise.

Ask for memory at run time

C
int *a = malloc((size_t)n * sizeof *a);
from C4.2 line 8 — compiled and run
Pythonno equivalent

Never. Objects are allocated when created and freed when the last reference goes away.

Rno equivalent

Never. R allocates on assignment and collects garbage on its own.

sizeof *a, not sizeof(int): change a's type later and the allocation follows it.

Check that the allocation worked

C
if (!a) { perror("malloc"); return 1; }
from C4.2 line 9 — compiled and run
Pythonno equivalent

An allocation that fails raises MemoryError; there is nothing to check.

Rno equivalent

R stops with 'cannot allocate vector of size…'. There is nothing to check.

Every malloc in this file is followed by this line. That is not style — an unchecked NULL is the second of the four memory bugs.

Give the memory back

C
free(a);
from C4.2 line 14 — compiled and run
Pythonno equivalent

The garbage collector does it. del removes a name, not an object.

Rno equivalent

The garbage collector does it. rm() removes a name, not an object.

One owner per allocation, and the owner frees it. Two owners is a double free; no owner is a leak.

Running total, running best

Second largest, without sorting

Second largest, runner-up, next best.

Two variables, updated in the right order: when a new best arrives, the old best becomes the second. Sorting first also works and costs O(n log n) to answer a question that needs one pass.

int best = INT_MIN, second = INT_MIN;
for (int i = 0; i < n; i++) {
    if (a[i] > best) { second = best; best = a[i]; }
    else if (a[i] > second && a[i] != best) second = a[i];
}
